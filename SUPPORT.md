# MarketPulseBar Support

This repository can be used for public MarketPulseBar bug reports and feature requests.

## Before opening an issue

Please check whether a similar issue already exists.

For bugs, include enough information to reproduce the problem:

- MarketPulseBar version
- macOS version
- affected symbol or market type, if relevant
- selected display mode
- what you expected to happen
- what actually happened
- steps to reproduce the problem
- screenshot or screen recording, when useful

## Market-data issues

MarketPulseBar uses Yahoo Finance as its market-data source.

Exact market coverage, symbol availability, and data behaviour depend on Yahoo Finance. If a symbol is unavailable or behaves differently from expected, mention the exact symbol in your issue so the problem can be investigated.

## Feature requests

Feature requests are welcome when they support MarketPulseBar's core goal:

> Keep useful market information visible from the macOS menu bar without turning it into a full trading dashboard.

Please describe the problem you want solved, not only the feature you want added.

## Security issues

Do **not** post security vulnerabilities publicly.

Follow the private reporting instructions in [`SECURITY.md`](SECURITY.md).
