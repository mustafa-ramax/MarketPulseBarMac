# MarketPulseBar README Assets

Before publishing the GitHub repository, add the MarketPulseBar screenshots used on the product/article pages to this directory.

Use these filenames so the main `README.md` renders without edits:

| Filename | Screenshot |
|---|---|
| `marketpulsebar-watchlist.png` | Watchlist showing stocks, crypto, ETFs, forex, gold, silver, or other supported symbols |
| `marketpulsebar-menu-bar-ticker.png` | Multiple symbols displayed in the macOS menu bar |
| `marketpulsebar-display-controls.png` | Controls for Multi, Rotate, Hybrid, Compact, or related display behaviour |
| `marketpulsebar-settings.png` | Watchlist, refresh, and display settings |

## Recommendations

- Prefer PNG or WebP screenshots with readable text.
- Crop unnecessary desktop space.
- Avoid showing private portfolio details or personal information.
- Keep screenshot widths reasonably consistent.
- Use the real MarketPulseBar interface rather than marketing mockups when possible.

The main README already includes descriptive alt text for each image.
