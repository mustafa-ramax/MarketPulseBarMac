# Security Policy

Thank you for helping keep MarketPulseBar users safe.

MarketPulseBar is a **closed-source macOS application**. This public repository contains product documentation and support resources; it does not contain the application source code.

## Reporting a vulnerability

**Please do not report security vulnerabilities through a public GitHub issue.**

Instead, contact the developer privately through:

https://mustafaramx.com/#contact

Please include, where possible:

- a clear description of the issue
- the affected MarketPulseBar version
- your macOS version
- steps required to reproduce the issue
- the potential security impact
- screenshots, logs, or proof-of-concept details that do not expose private credentials or financial information

## Please avoid including

Do not send:

- account passwords
- API keys or access tokens
- private financial account information
- personal portfolio data that is not needed to reproduce the issue
- third-party credentials

## Scope

Relevant reports may include security issues involving the MarketPulseBar application, its handling of local application data, or its interaction with supported market-data services.

Issues that are purely about incorrect or unavailable third-party market data may depend on the external data provider rather than MarketPulseBar itself.

Thank you for reporting security problems responsibly.
